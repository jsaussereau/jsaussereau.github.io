Ce projet vise à concevoir un système embarqué basé sur un microcontrôleur PIC16F877A. L'objectif est d'implémenter horloge une horloge configurable affichée sur un afficheur LCD. Le cahier des charges complet se trouve dans la [section suivante](/fr/posts/eel6-numu2/2_cahier_des_charges/).

## Compétences

Ce projet a pour objectif de développer les compétences suivantes: 
  - la programmation par interruptions
  - la configuration de périphériques
  - la structuration d'un code
  - la mise en place de couches d'abstraction 
  - la mise à profit d'une documentation technique

> [!CAUTION]
> L’utilisation d’IA générative **n’est pas autorisée** pour ce cours. Développer par vous‑même les compétences ci‑dessus est l'objectif de ce module. Cela vous permettra d’utiliser plus tard les outils d’IA avec beaucoup plus d’efficacité, de discernement et de recul. Même si la tentation est grande, **merci de jouer le jeu** 🙂 !
